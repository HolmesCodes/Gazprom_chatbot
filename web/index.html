Как пользоваться Софией

Задавайте вопросы по производственной документации на русском языке.

Команды:

  • /onboard — адаптация нового сотрудника
  • /search — поиск по документам
  • /recent — последние документы
  • /by_type — документы по типу
  • /faq — часто задаваемые вопросы
  • /contact — контакты

Нажмите на источник в левой панели, чтобы открыть полный текст чанка.

Используйте 🎤 для голосового ввода.
