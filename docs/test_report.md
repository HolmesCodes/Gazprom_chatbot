## Примечания

- **9 Skipped** — связаны с тем, что gemini-2.5-flash-lite консервативен и возвращает «Информация не найдена» на ряд вопросов. Это поведение модели, не баг системы.
- **Recall@3** требует ручной аннотации ground truth для реальных документов. Сейчас ключевые слова в ground truth не полностью совпадают с содержимым PDF.
- **MMR-поиск** даёт небольшой разброс между запусками из-за приближённых вычислений эмбеддингов — это нормальное поведение.
